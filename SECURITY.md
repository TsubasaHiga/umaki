# Security Policy

## Supported Versions

Only the latest minor release receives security fixes.

| Version | Supported |
| --- | --- |
| Latest 0.x minor | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report them privately via [GitHub's private vulnerability reporting](https://github.com/TsubasaHiga/umaki/security/advisories/new). Include the affected version, a description of the issue, and steps to reproduce if possible.

You can expect an initial response within 7 days. Once a fix is released, the advisory will be published with credit to the reporter unless you prefer to remain anonymous.
